# Varastonhallinta-projekti
Varastonhallinta projekti
https://github.com/Reena-tech2/Varastonhallinta-projekti/releases/tag/v1.0.0
Asennusohje
Lataa projekti GitHubista
Asenna Python 3.x
Asenna tarvittavat kirjastot:
pip install -r requirements.txt
Käynnistä ohjelma:
python "varastosovellus.py"

Sovellus avaa varastonhallinnan, jossa voit lisätä, poistaa ja päivittää tuotteita sekä määrää ja hintaa.
